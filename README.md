# 📌 PCD Assignment 2 - Transformasi Warna & Histogram
## 📖 Deskripsi
Tugas ini merupakan bagian dari mata kuliah Pengolahan Citra Digital yang berfokus pada Transformasi Warna dan Histogram.

## 🎯 Tujuan
- Memahami konsep transformasi warna dalam pengolahan citra.
- Menerapkan berbagai model warna (RGB, Grayscale, HSV, dll.).
- Menganalisis histogram citra untuk memahami distribusi intensitas warna.

## 🛠️ Isi dari kode / materi
1. RGB
2. RGB to Grayscale
3. Grayscale to Biner
4. RGB to CMY
5. RGB to HSI
6. Transformasi Negatif
7. Transformasi Citra Inverse
8. Transformasi Log
9. Transformasi Power Law Gamma
10. Histogram Tingkat Keabuan
11. a. Histogram Equalization RGB
11. b. Histogram Equalization Grayscale
12. Piecewise Linear Transformation Functions (Contrast strecthing dan intensity-level slicing)
13. Histogram Bit-plane slicing
14. Local Histogram Processing
15. Spesifikasi Histogram
